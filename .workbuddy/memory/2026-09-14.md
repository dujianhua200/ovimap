## 第二十七批：天地图瓦片矢量化（全域建筑/道路）（07:20-14:40）
- 用户要求：整个信阳（含农村县城）矢量数据——建筑轮廓/乡间小道/村庄房屋，GeoJSON，**明确拒绝 OSM**（"数据太不全"），要求"根据天地图矢量图动手矢量化"。
- **技术路线（自研，已打通）**：天地图**不提供 MVT 矢量瓦片**（`/mvt/`、`vec_mvt` 等接口全 404），只有渲染后的栅格 PNG → **栅格矢量化**：
  - `tool/tdt_vect.py`：单瓦片矢量化（建筑 + 道路）
  - `tool/xy_all.py`：按区县批量下载 + 多进程矢量化（10 县 bbox 已内置）
  - `tool/split_simplify.py`：Douglas-Peucker 简化 + 按 0.05° 网格分块
- **算法要点（踩坑记录，全部实测）**：
  1. 天地图 vec 瓦片配色：背景 bgr(238,244,245) / 建筑填充(243,250,249) / 道路纯白(251,252,252) / 灰描边 / 绿地 / 蓝水塘。**背景与建筑亮度仅差 4~7 → 绝对阈值不可分，必须用"与背景的差异"（建筑 diff≈15）**
  2. **建筑 = 灰描边围合的连通域**（`connectedComponents` + 排除与边界连通的 label）+ 补充"填充色连通域"（描边过浅的漏提）
  3. **道路 = 纯白区域骨架化**（`cv2.ximgproc.thinning`）
  4. ⚠️ **cv2.imread 是 BGR 顺序** —— 按 RGB 写水体判定会反转（曾把 2 万个水塘/绿地误判成建筑，建筑数从 37732 虚高到 58497）
  5. 几何过滤：面积、长宽比、填充率，排除路名文字
- **规模实测（关键约束）**：信阳 z=17 需 **50.7 万张瓦片**（1.01m/像素，10m 农村房屋≈10px 可提）；z=16 需 12.7 万（2.03m/px，农村房屋仅 5px 提不出）；z=18 需 202 万（不可行）。
- **⚠️ 最大阻碍：天地图 key 被限流** —— 下载到 1 万张后开始返回 **HTTP 429 `{"code":302010,"msg":"该tk已限流"}`**（内置 key 是共享的）。高德瓦片可作备选但成功率仅 37%（同样限流）；腾讯瓦片返回无效内容。**免费瓦片服务都不允许 50 万张的批量抓取**。
- **已产出（可用成果）**：浉河区已下载的 9930 张瓦片（约 1/3 区域）→ 建筑 37732 / 道路 50272 → 简化分块 **47 个文件 / 18.8 MB**（单块中位 0.45MB、最大 1.73MB）→ `~/Desktop/信阳矢量/分块/`，命名 `纬度_经度.geojson`。
- **待用户配合**：申请自己的天地图 key（console.tianditu.gov.cn，免费）才能继续全域；或缩小到指定作业区域先做。
- **另一条后台方式教训**：`nohup ... &` 启动的后台进程会被环境回收（只跑了 45 秒）；**必须用工具级 `run_in_background`**。
