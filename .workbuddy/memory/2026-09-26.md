### v3.9.2 导出道路裁剪 + 仓库转公开
- **导出道路"超级长"根因**：`BasemapFetcher` 的 roads crop 是「任一点在 bbox 内 → 保留**整条**」，于是横穿县城的国道只要蹭到 100m 范围就被整条（数十公里）写进 DXF。
  修：`cropRoadsToBbox` 按 bbox 把折线切成框内连续段，进出边界用 `clipSegToBbox` 二分插值收口（**方向自适应**：a 框内/b 框外时要交换，否则二分失效返回远端端点——踩过）。
- 护栏：test/road_clip_length_test.dart（40km 长路 → 只剩框内片段；框外整条丢弃）。
- **仓库转公开**：`gh repo edit --visibility public` 无效（仍 PRIVATE），必须 `gh api -X PATCH repos/<owner>/<repo> -f visibility=public`。公开后 Actions 不占私有额度，构建恢复（此前 billing 拒绝）。
- **内置 key 全部移除**（公开前必做）：`kBuiltinTiandituKey` / `kBuiltinAmapKey` 置空，docs/sop/04 脱敏；相关测试改为「用户配置 key」路径（原断言写死 key 字面值）。
