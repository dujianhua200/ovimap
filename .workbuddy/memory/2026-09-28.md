### v3.9.5 出图字号与路宽（用户四项样式要求）
- **根因（重要口径）**：DXF 是米制坐标，段距/标签字高此前直接写 `2.5/3` → 等于 **2.5 米高的字**，这才是"字太大"的真因。
  修：字高一律走 `_mmOf(mm, routeScale)` 纸面毫米换算；距离 2.5mm（宋体 SimSun），主标签 2.0mm，备注/盘留/光缆 1.5~1.6mm（"和谐匹配"的字号层级）。
- 路宽：半宽纸面表整体 ×2（trunk 0.45→0.90mm … other 0.10→0.20mm）；路名字高 clamp 随双线间隙自动变大（副作用，QA 镜像表需同步）。
- **DXF 字体事实**：STYLE 表注册了**两个**样式 —— SimSun（SimSun.ttf，业务文字）与 SongTi（simsun.ttc，**路名专用**）。别再把 SongTi 当未注册（我一度误判并改坏，已回退）。
- 护栏：test/dxf_style_spec_test.dart（只校验 JuLi 层字高 < 2.5；按实体 split 取层名，避免大文本正则回溯）。
- **git push 通道（运维）**：xray 代理 10808 会挂（LibreSSL SSL_ERROR_SYSCALL），此时 `env -u HTTPS_PROXY -u HTTP_PROXY -u https_proxy -u http_proxy git push` **直连反而可用**；gh（走 API）不受影响。判断方法：`curl -x http://127.0.0.1:10808 https://github.com` 返回 000 = 代理挂。
