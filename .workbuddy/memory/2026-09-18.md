### 本地环境踩坑（重要，下次直接用）
1. **本机 shell 有 HTTP 代理** `HTTP_PROXY/HTTPS_PROXY=127.0.0.1:56315`，会把
   `flutter_tester` 与测试进程之间的 localhost WebSocket 当外网劫持 →
   全部用例报 `Invalid WebSocket upgrade request`、`+0 -63` 全红。
   解决：跑 flutter 命令前 `export NO_PROXY="127.0.0.1,localhost,::1"`（小写也要设）。
2. **该 56315 代理连不上 github.com**（502 Bad Gateway），而**本机 10808 端口有可用代理**
   （v2ray 类客户端），经它访问 github.com / api.github.com 均 200。
   `gh` / `git push` 一律加 `HTTPS_PROXY=http://127.0.0.1:10808` 前缀。
   `api.github.com` 直连也通，但 `github.com` 直连超时。
3. `flutter analyze` **默认把 info 级 lint 也判为致命**（本项目有 68 条 info）→
   CI 门禁必须用 `flutter analyze --no-fatal-infos`，否则一推就红。
4. `gh auth login` 默认 scope 是 `gist, read:org, repo`，**没有 `workflow`**。
   推 `.github/workflows/` 下的文件会被 GitHub 拒绝，需
   `gh auth refresh -h github.com -s workflow` 补权限。
5. macOS `.app` 打包必须用 `ditto -c -k --sequesterRsrc --keepParent`，
   用 `zip` 会丢符号链接导致解压后打不开。
6. Windows runner 上写 `$GITHUB_ENV` 要用 pwsh + `Out-File -Append -Encoding utf8`，
   别用 Git Bash 重定向。

- ⚠️ **踩坑（新增，已修）**：`restore_confirm_indep_test.dart` 在 Windows 上抛
  `PathAccessException ... errno = 32`（删临时目录时仍有在途写盘句柄）。
  POSIX 可删打开中的文件，Windows 不行。已新增 `test/_fs_cleanup.dart`
  的 `deleteTempDirResilient()`（退让重试、失败只告警），用于 3 个涉及
  SyncController 的测试。**本地 macOS 全绿 ≠ Windows 全绿**。
- ⚠️ **可移植性问题（已修）**：`ovimap.exe` 导入 `MSVCP140.dll` /
  `VCRUNTIME140.dll` / `VCRUNTIME140_1.dll`，Windows 只自带 UCRT，不带这三个 →
  原 zip 的「免安装绿色版」名不副实。已在打包步骤从 VS 2022 的
  `VC\Redist\MSVC\*\x64\Microsoft.VC*.CRT` 拷入整套 VC143 CRT（回退 System32）。
- ⚠️ **验证 macOS 包时别直启二进制**：在本身被沙箱限制的 shell 里跑

### 待办 / 已知边界（用户选了「最小可运行」）
- `lib/main.dart` 仍用 `Platform.isWindows` 决定桌面壳，**macOS 会落到移动竖屏壳**。
  改成 `PlatformCaps.isDesktop` 即可获得真正的桌面三栏布局（`PlatformCaps.isDesktop`
  已含 macOS，`services/loc.dart` 也已按 isDesktop 降级）。
- `PlatformCaps.supportsFileSaveDialog` 写死 `Platform.isWindows`，
  macOS 上导出走的是降级路径而非系统「另存为」。
- macOS 包为 ad-hoc 签名，首次打开需右键「打开」或 `xattr -cr`。
- `android/.gitignore` 忽略了 `gradle-wrapper.jar` / `gradlew`，
  以后若要加 Android 云端构建，新克隆的仓库缺 wrapper 会失败。
- private 仓库的 Actions 有免费额度限制：macOS runner 消耗倍率 ×10、
  Windows ×2（免费 2000 分钟/月）。改成 public 可无限免费。
