### v3.9.3 底图改「沿线路缓冲 50m」，弃用矩形包围盒
- **关键认知（长期口径）**：导出底图的"范围"必须是**沿线路缓冲带**，不是「线路包围盒 + padding」。
  L 形/斜向/折返线路的矩形包围盒会把离线路几百米的角落也框进来，padding 再小也没用——
  用户（线路设计）两次反馈"太广/太长"的真因都在这。
- 实现：`BasemapFetcher.distToRouteM`（线组分段 + 点到段距离）、`cropRoadsToRoute`（带内连续段 + 进出边界二分插值收口）、
  建筑/地名同样按到线路距离过滤，出口兜底 `cropPlacesToRoute`。
- 默认 rangeM 100 → **50**；档位 30/50/100/200/300/500/880。
- 既有 QA 断言需按新口径同步（B20 样例第二条路离轨迹 >300m 被正确裁掉 → 断言改 ≥1）。
- **git commit 教训**：commit message 含中文引号/换行时 `git commit -m "..."` 会被 zsh 切碎 → 一律用 `git commit -F 文件`。

### v3.9.4 矢量数据来源调研 + 新增电力/水系一路
- **事实（已核实，别再臆测）**：
  - 高德**不开放**建筑/道路矢量几何（只有 POI、`district` 行政区边界）。
