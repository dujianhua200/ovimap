### v3.7.0 八条反馈（逐点撤销/标记模式/拖拽移入/触控板等）
1. **撤销逐点**：根因是打点不 push 快照，栈里只有 clearDraft 的空快照 → Ctrl+Z 一次撤光。修：addLabelAtWgs 落点前 pushUndoSnapshot。
2. **标记模式（重要新功能）**：`st.markMode` + 工具栏图钉开关；任何模式点地图落独立符号（lineGroupId 空、不进草稿），`_appendToMarkBook` 自动追加到根目录「标记」收藏（无则建）并 refreshCollections+visibleCids 上屏。注意 name 计数只用 `_markCount+1`（曾误加 collections 计数导致跳号）。
3. **拖拽移入**：列表项 Draggable + 树行/根行 DragTarget（_treeRow 加 dropTargetId 参数），onWillAccept 拒绝同层。
4. **触控板根因（macOS 硬问题）**：trackpad 双指平移/捏合是 `PointerPanZoom*` 事件，flutter_map 的 scrollWheelZoom 只认 `PointerScrollEvent` → 触控板全失效。修：地图外层 `Listener(onPointerPanZoomStart/Update)` 自实现——pan 像素→相机度数平移（mpp/111320 换算），scale→zoom+log2。**本机就是 macOS 触控板，用户下轮大概率直接给反馈，若仍不好要查 Flutter 对 macOS trackpad 的事件类型。**
5. 新建文件夹（面板标题栏按钮）parentId='' 落根；右键「新建子文件夹」仍在原层。
6. 右栏属性加符号样式替换 Dropdown（LabelType.all，草稿/收藏点通用，_dirty→保存改动落盘）。
7. 工具栏删「收起左栏」按钮；toast 指引更新。
