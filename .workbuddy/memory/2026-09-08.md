# 2026-09-08 第三批：设计人员视角全链路逻辑审查（用户："自己把所有逻辑用一遍，大刀阔斧改到满意"）

## 抓到的真 Bug（全部修复）
1. **杆路被箱体剪断（最严重）**：地图连线 _buildSegLines 是"向前搜索同组点"（穿箱连续），但 DXF/KML/CSV 用"相邻两点同组"判定——箱体插两杆之间导出的杆路是断的，地图与导出口径不一致。→ lib/models/map_label.dart 新增统一 `buildLabelChains()` + `isLineMember()`，home_page 地图连线、dxf 主路由/桩号、kml 折线+段距、csv 材料统计/工程量/对比全部改链口径。
2. **导入"同位置"判定失效**：6 位小数全等几乎永远不命中（GPS 两次打点不可能相同）→ _mergeBoxes 改同类型 5m 近邻判定。
3. **覆盖确认弹窗取消后仍导入**：drawer_panel 的 result 被丢弃、home_page 的 doImport!=true 连"确定不勾选覆盖"也被拦。→ 取消=pop(null) 不导入；确定=导入，勾选决定覆盖（两处统一语义）。
4. **竣工段距基准错位**：showCompletionSegment 取列表紧邻上一点做基准，中间插箱体/文字算错段 → AppState.previousChainLabel(同组上一杆)，弹窗显示"上一杆：xxx"。

## 新增能力
- 管廊双线整链闭合偏移多段线（平均法向转角对接，不再逐段封口出头）_appendCorridor。
- 杆路点表（更多菜单）：按链分组列点（名称/段距/盘留/型号/备注），点击定位+开属性；链头显示全长。
- 信息栏采集中实时显示"已连Xm/N段"。
- 属性对话框「移到当前定位」按钮（现场纠点位）。
- 竣工确认弹窗加：敷设方式 radio + 盘留输入。
- 拉直配线主干排除纯轨迹链。
