# 通信线路设计&竣工绘图软件重构设计

> 来源：用户 2026-10-03 规格书（对标主流软件+行业专属功能）
> 目标：轻量化通信光缆路由设计、拓扑配线自动生成、竣工资料一键出图出表

## 一、核心架构：三图联动

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   路由图     │────▶│   拓扑图     │────▶│   配线图     │
│ (地图底图)   │     │ (人工连线)   │     │ (自动生成)   │
│ 布设点位/杆路│     │ 逻辑关系     │     │ 右侧排布     │
└─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │
       └───────────────────┴───────────────────┘
                    数据同源 (TelecomProject)
```

### 数据模型

**TelecomDevice（设备节点）** — 扩展现有 MapLabel
- 保持现有字段兼容（id/typeId/lat/lon/name/note）
- 新增：deviceCategory（设备大类）、customNo（用户编号）、autoNo（自动编号）
- 独立节点锁定：isStandalone=true 的设备不参与自动连线/拓扑推演

**FiberLink（光缆拓扑连线）** — 新增
- id, fromDeviceId, toDeviceId（人工指定）
- cores（芯数：6/12/24/48/96/144/自定义）
- cableModel（光缆型号，如 GYTS）
- manufacturer（厂家）
- layMethod（敷设方式：架空/管道/直埋/引上）
- lengthM（长度，米）
- spliceMethod（熔接方式）

**PoleSegment（杆路段）** — 杆路分段独立管理
- id, name（分段命名）, points（点位链）
- material（材质）, buildYear（建设年代）
- 独立台账、独立编辑

编号规则：用户自定义优先 → 空白按「类型简称+序号」（如 GX-01, FH-01）

## 三、拓扑图（人工）

- 无自动拓扑、无自动挂接、无层级推断
- 点击拓扑面板 → 汇总路由图所有设备点位
- 手动选择起点/终点 → 弹窗填光缆参数 → 保存连线
- 支持连续批量连线
- 拓扑校验：孤立节点、重复连线、芯数冲突、未命名检测

## 四、配线图（自动）

- 不独立绘制，完全由拓扑连线自动生成
- DXF 导出时：路由图居左、配线图居右，间距自适应
- 图层分类：路由层/设备层/配线层/文字层

## 五、竣工报表（Excel）

1. 光缆纤芯台账：起止点、芯数、型号、长度、敷设方式
2. 设备清单：编号、类型、型号、位置、数量
3. 工程量统计：电杆数、杆距、架空长、管道长、人手孔数
4. 材料汇总：按型号汇总光缆、设备数量
