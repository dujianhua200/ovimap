# 滑洲云图 ovimap —— 使用手册

> 面向：拿到程序后要真正干活的人。
> 与 [README](../README.md) 的分工：README 讲「有什么、怎么装」；本手册讲「怎么一步步把活干完」。
> 功能入口速查看 [README §5 界面导航](../README.md#5-界面导航)，这里只给**操作流程**。

---

## ⚠️ 请先确认你用的是哪个界面壳

本手册的步骤按「**菜单路径**」写法（如「文件 → 新建工程」），这套路径对应
**Windows 桌面壳**。顶层界面壳的分支条件是 `Platform.isWindows`（`lib/main.dart:87`）：

| 平台 | 界面 | 手册怎么读 |
|---|---|---|
| **Windows** | 桌面三栏壳 | 严格按本手册的菜单 / 快捷键路径操作 |
| **macOS** | 移动竖屏壳 | 业务功能完全一致，但入口在**左侧抽屉面板**与**「工具」/「设置」菜单**里；把手册里的「菜单 X → Y」理解为「在抽屉/工具菜单里找同名项」 |
| **Android** | 移动竖屏壳 | 同上 |

下表给出两套壳的入口对照，避免 macOS / Android 用户找不到：

| 要做的事 | Windows 桌面壳 | 移动壳（macOS / Android） |
|---|---|---|
| 新建 / 打开 / 导出工程 | 菜单「文件」 | 左栏抽屉 →「工程」区按钮 |
| 撤销 / 重做 / 删除 / 批量编辑 | 菜单「编辑」或快捷键 | 「工具」菜单 |
| 工程模板 / 自动布杆 / 点表 / 轨迹核查 | 菜单「工程」 | 「工具」菜单 |
| 图源 / 坐标格式 / 离线地图 / Key 设置 | 菜单「底图」 | 「设置」菜单 |
| 云同步 | 菜单「同步」或工具栏 🔄 | 「设置 → 云同步」 |
| 打点 / 连线 / 测距 / 轨迹 | 顶部工具栏 | 底部工具条 |

> macOS 没有菜单栏 / 工具栏 / 快捷键是 **v3.0.2 的已知状态**，不是故障；
> 修复只需把 `main.dart:87` 的 `Platform.isWindows` 换成 `PlatformCaps.isDesktop`，
> 计划下一版本统一。

## 0. 先搞懂三个概念

| 概念 | 是什么 | 在哪 |
|---|---|---|
| **草稿（Draft）** | 当前正在画的这一坨点，实时自动落盘 | 地图上可见即草稿 |
| **工程（Collection）** | 一次「保存收藏」后的成品，是导出与出图的基本单位 | 左栏工程列表 |
| **文件夹（Folder）** | 工程的分组，支持多层嵌套 | 左栏目录树 |

关系：

```
文件夹 ──► 工程（Collection，= 一个 .ovimap 文件）
                └── 点集（labels：符号 / 编号 / 坐标 / 敷设方式 / 光缆型号 / 盘留）
草稿 ──[Ctrl+S 保存收藏]──► 工程
工程 ──[打开]──► 草稿（编辑中）──[Ctrl+S]──► 覆盖回该工程
```

> **关键提醒**：**导出对象是「工程」，不是草稿**。
> 打完点先 `Ctrl+S` 存成工程再导出；若只打了草稿就 `Ctrl+E`，程序会提示没有可导出数据。

## 1. 场景一：架空光缆勘察出图（最常见）

**目标**：沿杆路打点 → 自动布杆 → 算档距 → 出 CAD 路由图。

### 步骤

| # | 操作 | 说明 |
|---|---|---|
| 1 | 菜单「文件 → 新建工程」 | 填工程名，如 `XX路架空光缆` |
| 2 | 菜单「工程 → 工程模板」→ 选「**架空光缆**」 | 套用符号与编号规则 |
| 3 | 菜单「工程 → 采集设置」 | 设杆号前缀（如 `G`）与起始号（如 `1`）→ 打点自动编号 `G001`、`G002`… |
| 4 | 菜单「底图 → 图源 / 图层」 | 选底图。**架空杆路建议用卫星影像**（联通卫星+注记 / 高德卫星 / 星图地球影像），杆位看得清 |
| 5 | 工具栏点「**打点**」 | 进入打点模式 |
| 6 | 沿线路逐个点击落点 | 每点一次落一个杆位，编号自动递增；**打完不弹窗**，可以一路走一路点 |
| 7 | 打完 → 再点一次「打点」退出 | 避免误触继续加点 |
| 8 | 工具栏「**连线路（拓扑）**」 | 依次点选杆点，把杆路连成链；右键结束 |
| 9 | 菜单「工程 → **自动布杆**」 | 输入平均档距（如 50 m）与杆型 → 沿已画路径等距补杆并自动编号；适合长距离快速成形 |
| 10 | 菜单「工程 → **杆路轨迹核查**」 | 校验杆点与轨迹偏离度，揪出打偏的点 |
| 11 | 右栏看**统计面板** | 分类计数 / 分段长度 / 盘留汇总 |
| 12 | `Ctrl+E` → 「📐 DXF 路由图」 | 勾选项 → 导出 |
| 13 | `Ctrl+S` 保存收藏 | 留档，下次可继续 |

### DXF 勾选建议（架空光缆）

| 选项 | 建议 |
|---|---|
| 输出符号块 | ✅ |
| 杆路里程桩号 | ✅ 长杆路必开，竣工核对快 |
| 图例栏自动生成 | ✅ |
| 竣工图红色描边 | 竣工阶段开，设计阶段关 |
| 附加拉直沿线配线图 | 杆路很长（分幅出图）时开 |
| 自动添加周边底图矢量 | ✅ 出图带建筑与路名，甲方看得懂 |
| R2000 专业格式 | 不确定就用默认 **R12** |

## 2. 场景二：管道光缆勘察出图

**目标**：人孔 / 手井定位 → 管廊连线 → 出管道路由图与手孔点表。

### 与架空场景的差异

| 环节 | 差异 |
|---|---|
| 模板 | 选「**管道光缆**」，主用符号变为**人孔 / 手井**（椭圆形态） |
| 底图 | 卫星 + 街道图配合看，人孔多在路边 |
| DXF 选项 | **「管廊双线」勾上并填走廊宽度**（米，常见 2），管廊会画成双线；不填 = 单中心线 |
| 附加导出 | 「📋 杆点坐标 CSV」→ 实际是**手孔点位表**，给施工队 |
| 附加导出 | 「🧾 工程量清单 CSV」→ 451 号文口径，直接进预算 |

### 步骤

```
新建工程 → 模板选「管道光缆」→ 采集设置设井号前缀（如 R）
→ 打点（每个井一个点）→ 拓扑连线成管道路由 → Ctrl+S 保存
→ Ctrl+E → DXF（勾「管廊双线」+ 填宽度）→ 同时导出「杆点坐标 CSV」与「工程量清单 CSV」
```

> **口径提示**：工程量清单按 451 号文口径生成（技工 **114 元/工日**、辅助材料 **0.3%**），
> 与通算宝预算引擎一致。清单是「自动汇总的草稿」，正式报量前请按项目实际定额复核。

## 3. 场景三：箱体配线（拓扑 + 芯线占用）

**目标**：光交 → 分光器箱 → 分纤盒 → ONU 箱的层级连线，出配线拓扑图与芯线占用表。

### 拓扑角色

程序按符号的**拓扑角色**自动组织层级，不需要手工分层：

| 角色 | 对应符号 |
|---|---|
| 分光器 | 分光器箱 |
| 分纤盒 | 分纤盒 |
| ONU | ONU 箱 |
| 交接箱 | 交接箱 |
| 杆路 | 水泥杆 / 木杆 / 电力杆 |
| 管道 / 井 | 管道口 / 人孔 / 手井 |
| 机房 / 局端 | 机房 / 基站 |
| 终端 | 末端点 |

### 步骤

| # | 操作 | 说明 |
|---|---|---|
| 1 | 新建工程 → 模板「**箱体配线**」 | |
| 2 | 先打箱体点 | 光交 / 分光器箱 / 分纤盒 / ONU 箱，**这些是「独立个体」，不参与杆路连线**（杆路线会从它们中间穿过继续连） |
| 3 | 再打杆路 / 井点 | |
| 4 | 工具栏「**连线路（拓扑）**」 | 按「上级 → 下级」依次点选成链 |
| 5 | 菜单「工程 → 拓扑连线指引」 | 不确定连线方向时看这里 |
| 6 | 右键改点属性 | 设**光缆型号**、**敷设方式**、**盘留** —— 芯线占用表依赖这些字段 |
| 7 | `Ctrl+E` → 「🖼 配线拓扑图 PNG」 | 1400px 宽，可直接插进方案文档 |
| 8 | `Ctrl+E` → 「🔌 芯线占用表 CSV」 | **含校验**，导出后弹提示告知告警条数 |

> 芯线占用表导出时若提示「发现 N 条告警」，说明存在未填光缆型号、芯数不匹配、
> 或同一芯被重复占用的情况 —— 先回右栏核对再报出去。

## 4. 场景四：竣工测量与资料成册

**目标**：记录实际竣工路由 → 与设计对照 → 一键打包全套竣工资料。

| # | 操作 | 说明 |
|---|---|---|
| 1 | 打开设计工程（`Ctrl+O` 或左栏双击） | |
| 2 | 切到**竣工模式** | 竣工模式记录实际路由与**实测距离**，与设计模式数据并存 |
| 3 | 沿实际路由重新打点 / 连线 | 实测距离不是算出来的，是记录下来的 |
| 4 | 菜单「**设计↔竣工变更对照**」 | 输出差异报告：新增 / 删除 / 位移 / 长度变化 |
| 5 | `Ctrl+E` → DXF，勾「**竣工图红色描边**」 | 竣工图惯例：杆路 / 管廊红色描边 |
| 6 | 菜单「文件 → **竣工资料一键成册**」 | 一次性打包：图纸 + 各 CSV + 照片册，输出 ZIP |
| 7 | 竣工照片册 | 单独入口在导出中心，把随工照片按点位归集打包 |

> **成册内容**：竣工图纸（DXF）、杆点表、芯线占用表、材料统计、工程量清单、
> 照片册、变更对照 —— 一个 ZIP 交出去。具体清单以「竣工资料一键成册」对话框内列出的为准。

## 5. 功能详解

### 5.1 打点与编辑

| 操作 | 怎么做 |
|---|---|
| 切换符号 | 底部符号条横向滚动选择，点一下即切换 |
| 编辑已有点 | **右键点该点** → 「编辑属性」→ 改符号 / 编号 / 备注 / 光缆型号 / 敷设方式 / 盘留 |
| 续画分支 | 右键点 → 「续画分支」，从该点接着往下画 |
| 拖动点 | 右键 → 「拖动点」，把点拖到准确位置 |
| 复制坐标 | 右键 → 「复制坐标」，粘到别处 |
| 删除点 | 右键 → 「删除点」，或选中后按 `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） |
| 清空草稿 | 菜单「编辑 → 清空草稿」（会二次确认，显示将删多少个点） |

### 5.2 拓扑连线

- 入口：工具栏「连线路（拓扑）」，或菜单「工程 → 拓扑连线指引」看说明。
- 依次点选参与拓扑的节点（交接箱 / 分光器箱 / 分纤盒 / ONU 箱 / 机房 / 基站 / 引上），
  程序按点选顺序建链。
- 连错了：工具栏「撤销」回退一步，或彻底退出重新连。
- **杆路线与箱体线是两套**：杆路点连绵成线；箱体点是「独立个体」，画杆路时从它们"穿过"继续连。

### 5.3 自动布杆

菜单「工程 → 自动布杆」，填：

| 参数 | 说明 |
|---|---|
| 平均档距 | 米。常见 50 m（架空）、按项目实际填 |
| 杆型 | 水泥杆 / 木杆 / 电力杆 |
| 编号前缀 | 如 `G` |

沿已画路径**等距**落杆并自动编号（`lib/geo/route_layout.dart`）。
适合「先沿线画一条粗路由，再自动铺杆」的高效打法。

### 5.4 轨迹记录

| 操作 | 说明 |
|---|---|
| 开始 | 工具栏「轨迹记录」 |
| 暂停 / 继续 | 中途停下歇会儿，继续时接上 |
| 结束 | 自动存为一条「轨迹」类型的收藏 |

用途：① 记录实际行走路径；② 给「杆路轨迹核查」做基准。

### 5.5 测距 / 测面积

- 工具栏「测距 / 测面积」下拉选择模式。
- **测距**：连续点选，逐段累加，结果标在地图上。
- **测面积**：连续点选围合，输出多边形面积。
- 想留档：菜单里「保存测量为工程」。

### 5.6 批量编辑

1. 地图上**框选**，或在左栏线组里选中一批点；
2. 菜单「编辑 → 批量编辑」；
3. 统一修改：符号 / 敷设方式 / 光缆型号 / 盘留。

> 一次改一批杆的敷设方式或光缆型号时，这个比一个个右键快得多。

### 5.7 杆路轨迹核查

菜单「工程 → 杆路轨迹核查」。
比对**杆点连线**与**实际轨迹**，标出偏离超过阈值的点 —— 通常是现场打点手滑，或者
杆位记错。竣工前跑一遍，能省掉返工。

### 5.8 杆路点表

菜单「工程 → 杆路点表」：一览全部杆点的编号、坐标、档距。
出图前拿它对照设计交底，出图后拿它给施工队。

## 6. 工程文件（`.ovimap`）

### 6.1 是什么

**`.ovimap` 就是 `collection_<id>.json` 的原文件**（不引入新格式，零解析歧义）：

```json
{
  "id": "...",
  "name": "XX路架空光缆",
  "kind": "label",
  "folderId": "...",
  "editMode": "design",
  "labels": [ { "type": "concrete", "name": "G001", "lat": ..., "lon": ..., ... } ],
  "distances": [ ... ]
}
```

### 6.2 怎么用

| 操作 | 入口 |
|---|---|
| 导出工程文件 | 菜单「文件 → 导出工程文件(.ovimap)」—— 把**当前打开的工程**原文另存为 `<工程名>.ovimap` |
| 打开工程文件 | `Ctrl+O` 或菜单「文件 → 打开工程文件(.ovimap)」→ **新建**一个工程（重名自动追加 `(2)/(3)…`，**绝不覆盖**既有工程）并自动打开 |
| 双击打开 | Windows 已注册文件关联时，双击 `.ovimap` 直接启动并打开（注册见 `scripts\install_association.ps1`） |
| 拖放打开 | Windows 上把文件拖到窗口任意位置 |

### 6.3 取舍

`.ovimap` **不含照片与底图**。原因：照片本来就是按相对文件名引用、底图是项目级缓存，
都不随工程单文件走。要整机迁移，直接把 `labels/` 目录整拷（跨端目录结构逐字一致）。

## 7. 导出对应关系速查

| 你要的东西 | 导出项 | 备注 |
|---|---|---|
| 给设计的 CAD 图 | 📐 DXF 路由图 | 默认 R12 最广兼容；需图层线宽/真彩/填充勾 R2000 |
| 给甲方看的示意图 | 🖼 配线拓扑图 PNG | 1400px 宽 |
| 给谷歌地球 / 奥维看 | 🌍 KML | |
| 点位总表（Excel） | 📋 杆点坐标 CSV | |
| 芯线占用与校验 | 🔌 芯线占用表 CSV | 含校验，会报告告警条数 |
| 材料汇总 | 📊 材料统计表 CSV | 分类数量 / 分段长度 / 盘留 |
| 报价 / 报量 | 🧾 工程量清单 CSV | **451 号文**口径 |
| 一整套竣工资料 | 菜单「文件 → 竣工资料一键成册」 | 输出 ZIP |

**DXF 版本怎么选**

| 版本 | 何时用 |
|---|---|
| **R12**（默认） | 不确定就用它。兼容性最广，老 CAD 也能开；已用 ezdxf 严格打开验证 |
| R2000 | 需要图层线宽 / 真彩 / 建筑填充 HATCH 时。部分老 CAD 打开会提示"修复" |

导出前程序会跑一遍 DXF 结构自洽校验（`lib/export/dxf_validate.dart`），
不合法直接拦下 —— 避免出一个打不开的文件浪费时间。

## 8. 云同步怎么用

### 8.1 首次配置

1. 菜单「同步 → 云同步面板」，或点工具栏 🔄；
2. 「同步设置」里填**服务器地址**与**同步令牌**（部署方法见 [`DEPLOY-sync.md`](DEPLOY-sync.md)）；
3. 同一令牌的电脑与手机即可双向同步。

> **不配也能用**：未配置令牌时，本地建工程 / 打点 / 连线 / 导出 DXF / 导入 GeoJSON 全部可用。
> 云同步是增强能力，不是前置依赖。

### 8.2 状态怎么读

工具栏同步按钮右下角的圆点：

| 颜色语义 | 状态 |
|---|---|
| 灰 | 仅本地（未接入同步） |
| 有「待上传 N」 | 有本地改动未上传 |
| 正常色 | 已同步 |
| 警示色 | 冲突 |

鼠标悬停有完整文字提示。

### 8.3 冲突了怎么办

程序用**乐观并发**：上传时带本地 `rev`，服务端 `rev` 不匹配就判冲突，
弹冲突对话框让你选，**不会静默覆盖**，必要时生成**冲突副本**。

处理完两边数据都还在 —— 这是刻意的设计，宁可多一个副本，不可少一条数据。

### 8.4 版本回滚

「云同步面板 → 版本历史」列出每次同步留下的版本，可回滚到任一历史版本。
改错了工程（比如误删一批杆点后已同步）时，这是最后的救命索。

## 9. 数据在哪、怎么备份

| 平台 | 位置 |
|---|---|
| Windows | `%APPDATA%\ovimap\`（= `C:\Users\<你>\AppData\Roaming\ovimap\`） |
| Android | `<外部存储>/ovimap/` |
| macOS（沙箱版） | `~/Library/Containers/com.dujianhua.ovimap/Data/...` |

目录结构：

```
ovimap/
├── labels/
│   ├── index.json                工程索引
│   ├── collection_<id>.json      各工程数据（.ovimap 的原文）
│   ├── export/                   导出产物（含批量导出）
│   └── ...
├── tiles/                        瓦片缓存（可清）
└── basemap/                      本地矢量底图（GeoJSON 导入）
```

**备份建议**

| 目的 | 做法 |
|---|---|
| 备份单个工程 | 「文件 → 导出工程文件(.ovimap)」，拷走那个文件 |
| 整机迁移 | 整拷 `labels/` 目录（Windows ↔ Android 结构逐字一致） |
| 清缓存腾空间 | 菜单「底图 → 存储清理」（只清瓦片，不动工程数据） |

## 10. 效率技巧

| 想做的事 | 快法 |
|---|---|
| 打一批点 | 打点模式下一路点，编号自动走，别退出来 |
| 长杆路布杆 | 先画粗路由 → 拓扑连线 → 「自动布杆」等距铺杆 |
| 改一批杆的敷设方式 | 框选 → 批量编辑 |
| 连续出图 | DXF 的勾选项**记忆上次选择**，同一个工程连出多张不用重设 |
| 现场没信号 | 提前「底图 → 离线地图」预下载范围；或用 GeoJSON 本地底图出图 |
| 找点 | `Ctrl+F` 聚焦左栏搜索 |
| 收起侧栏看图 | 工具栏最右两个箭头 |
| 快速验证 DXF 对不对 | 先出一份只勾「输出符号块」的最小图，CAD 里确认无误再出全要素图 |
