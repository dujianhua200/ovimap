# 滑洲云图 · 交互逻辑契约（v3.8.0 定版）

> 这份文档是**收藏夹与地图交互的单一真源**。v3.4～v3.7 期间因为逐条打补丁，
> 同一批条目在两处渲染、同一手势出现三种语义，导致"越改越乱"。
> 从此以后：**任何新功能必须挂进下面的矩阵**，不得新增第四种交互语义。

---

## 1. 数据模型（谁是谁）

| 对象 | 类型 | 存哪里 |
|---|---|---|
| 文件夹 Folder | `{id, name, parentId}` | `folders.json`（树形，任意深度） |
| 工程 CollectionMeta | `{id, name, kind, folder, editMode, count}` | `index.json` |
| 点 MapLabel | `{id, typeId, lat, lon, name, note, lineGroupId…}` | `collection_<cid>.json` |
| 标记收藏 | `kind == 'mark'`，名字「标记」，**只存独立标记点** | 同上 |

**工程 kind 一览**：`label`（设计/竣工杆路）· `mark`（标记）· `track`（轨迹）· `data`（数据）

---

## 2. 视图职责（一个东西只在一处出现）

| 区域 | 只负责 | 不负责 |
|---|---|---|
| **收藏夹树**（左栏，**唯一视图**） | **全部条目**：根 → 文件夹 → 工程 → 标记点，层层缩进；折叠、选中、拖拽、右键 | 不重复渲染任何条目 |
| **条目工具条**（树上方） | 全选 / 取消 / 导出所选 / 删除所选(N) / 新建文件夹 —— **批量能力的可见入口** | 不做单条操作（走右键） |
| **右栏属性面板** | 选中点的属性编辑与「保存改动」 | 不做列表操作 |
| **主工具栏** | 模式开关与全局命令（保存/撤销/导出/标记…） | 不做条目管理 |

> 「所有东西都在收藏夹根目录」的呈现口径：选中「收藏夹（根目录）」时，
> 列表即根目录的全部工程与标记点。

---

## 3. 交互矩阵（唯一合法语义）

| 对象 | 左键单击 | 右键 | 拖拽 | Ctrl+左键 |
|---|---|---|---|---|
| **文件夹** | 选中该层（并展开） | 删除所选 / 新建子文件夹 / 重命名 / 删除（级联）/ 存当前画布到此 | 拖入另一文件夹（防成环） | 多选 |
| **工程** | 打开该工程 | 删除所选 / 打开 / 重命名 / 移动… / 导出 DXF / 删除 | 拖入文件夹 | 多选 |
| **标记点** | **只定位，绝不弹窗** | 删除所选 / **查看修改属性** / 移动到文件夹… / 删除 | 拖入文件夹（并入该层「标记」） | 多选 |

**折叠**：文件夹行前缀 `+`（收起）/`−`（展开），未记录=展开。
**显隐**：工程行右侧眼睛图标；标记随其所在「标记」收藏整体显隐。
**批量操作三条路（都必须可见）**：① 工具条按钮「全选 / 删除所选(N)」；
② 任意行右键菜单顶部「删除所选 N 项」；③ 快捷键 `Ctrl+A` 全选、`Delete` 删除。
**Shift 范围选**：以行顺序（可见行）为准，锚点=上次点击行。

---

## 4. 模式（互斥，工具栏切换）

| 模式 | 进入 | 地图左键行为 | 退出 |
|---|---|---|---|
| 普通 view | 默认 | 点选点/线段 → 右栏显示属性 | — |
| 设计编辑 edit | 「设计」开关 | **落点连线**（续画上一点） | 再点开关 |
| 竣工编辑 | 模式菜单 | 落点（不弹属性框） | 模式菜单 |
| **标记 mark** | 工具栏图钉 | 落**独立标记**并自动存「标记」收藏，**完成后自动退出** | 自动 / 再点图钉 |
| 测量 / 框选 / 拓扑 | 各自按钮 | 量距、框选、箱体连线 | Esc 或再点 |

**跨工程纪律**：打开收藏 / 新建工程后，第一笔**绝不接**旧工程末点（`_chainBroken`）。
**撤销纪律**：逐点回退（每次落点前压快照）；Ctrl+Z 一次只退一个点。

---

## 5. 目录层级纪律（放哪儿）

- 新建文件夹 → **收藏夹根目录**（面板标题栏按钮）；右键「新建子文件夹」→ 该层内。
- 新建工程 → 保存时默认落**根目录**（对话框可改）；工程可拖拽/移动到任意层。
- 标记 → 自动落**根目录「标记」**；可拖拽/移动到其他层（落到该层的「标记」）。

---

## 6. 改动前的自检清单（防再乱）

1. 这个功能属于**哪一类对象**？放进交互矩阵的哪一格？
2. 是否在**第二处**重复渲染了同一数据？（禁止）
3. 是否引入了**第四种手势语义**？（禁止）
4. 数据落盘：改完是否走 `_saveDraft()` / `store.finishCollection()`？（否则重启即丢）
5. 是否破坏既有护栏测试？（`favorites_stack_nav_test` / `collection_autosave_indep_test`）
